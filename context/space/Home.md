Fig.3D creates interactive companions to materials science papers, beginning with energy materials, nanomaterials, and electrochemistry. Each companion connects physical intuition, formal terminology, an explorable model, experimental observables, and the paper’s actual claims.

The first active companion is Lithium Pathways in Rocksalt Cathodes. The project workspace holds plans and verification records; source code and public releases will have separate homes.

## Release policy

Human expert review is optional and is not required for release. Required verification follows source traceability → explicit model specification → independent reference and fixture tests → model and invariant tests → adversarial AI critique → browser and visual semantic checks → approved publication. AI agreement is not empirical validation or peer review.
