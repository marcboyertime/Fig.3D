## Release checklist

- [ ] Sources and figures have exact versions and locations.

- [ ] Every substantive claim has a ledger entry.

- [ ] Model specification and omissions are visible.

- [ ] Independent reference or fixture checks pass.

- [ ] Model and invariant checks pass.

- [ ] Adversarial AI findings are resolved or reflected in narrower claims.

- [ ] Browser, accessibility, and visual semantic checks pass.

- [ ] Verification report names the exact release artifact.

- [ ] Website copy, credits, rights, and corrections path are ready.

- [ ] Publication is approved for the documented scope.

Human expert review is optional. Do not delay release solely to recruit a reviewer. If performed later, add expert-reviewed only for the documented scope and version.
