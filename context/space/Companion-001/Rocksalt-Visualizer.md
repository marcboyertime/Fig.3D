## Scientific display constraints

A moving marker is a path connectivity probe until a physical trajectory model with rates and occupancy constraints is explicitly implemented and checked. Arbitrary animation speed is not a measured diffusion timescale.

Distinguish hidden contextual atoms from physically absent atoms. State composition denominators, integer rounding, random seed, finite size, and the meaning of the order control. Separate local favorable environment counts from system spanning connectivity.
