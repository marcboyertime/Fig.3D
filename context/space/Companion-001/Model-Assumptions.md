This is the working model specification for the rocksalt companion. The existing code must be recovered before these fields can be confirmed. The entries below distinguish known teaching intent from unresolved implementation details.

## Intended scope

Teach the relationship between local lithium migration environments and connected transport pathways. The initial model is a teaching representation. Physical trajectories, calibrated rates, and quantitative battery performance are not established by the available record.

## Interpretation limits

The prior blueprint warns that a literature discussion of roughly 9 percent lithium excess belongs to a particular fully random cation model. Preserve it as a source claim requiring exact conditions; do not turn it into a universal threshold or a guarantee for one finite teaching crystal.

Geometric connectivity alone does not provide diffusivity, rate capability, capacity, or a measured timescale. A display toggle is not a material change. A structural comparison needs a declared physical state.

## Before implementation changes

Complete entities, coordinates, occupancy, graph rules, boundaries, parameter limits, outputs, omissions, and independent fixtures. Keep scientific calculations separate from rendering so checks can run without the viewer.
