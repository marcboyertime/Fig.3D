# Broader Fig.3D context

The space directory contains 15 verbatim-content Page exports with provenance and dated status caveats. Read them for the broader vision, audience, companion format, science standards, future topics, engineering/hosting proposals and launch policy. They predate the current site prototype. Newer instructions in DESIGN_AND_PRODUCT_HANDOFF and actual evidence in ENGINEERING_STATE supersede stale progress claims.

Fig.3D is intended to become a broad, trustworthy materials-science library/publication of individual interactive scientific visualizations and paper companions. The current homepage and battery example are one implementation slice. Do not narrow the brand to batteries, turn it into a course portal, or invent commitments from backlog ideas. Learn/Explore/Verify remains a useful depth pattern, not a required course navigation shell. A companion connects physical intuition, correct terminology, an explorable declared model, experimental observables and the paper's actual claims.

Historical migration limits are preserved rather than filled with invented context. Some older download files remain unrecovered. The current supplied original rocksalt HTML, source screenshot, native figure, paper PDF and fresh scoped audit are in site/references. Human expert review is optional and not a release gate throughout.
