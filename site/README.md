# Fig.3D — local interactive library prototype

Run from this folder with `python3 -m http.server 4173 --bind 127.0.0.1`, then open `http://127.0.0.1:4173/`. Use an HTTP server, not file://. No build or package installation is required; Three.js, Sora and source images are bundled.

The homepage transforms an actual paper figure into one ideal 1-TM lithium hop. The clean battery teaser opens a real 3D cell with charge/discharge mode, continuous directional markers at fixed selected composition, and a graphite interior. Diffusion remains a separate older preview; impedance is planned.

Read `battery-notes.md` and `references/hop-scientific-audit.md` before scientific changes. Run `node hop-verification.mjs`, `node hero-controller-verification.mjs`, `node battery-verification.mjs`, and `node battery-controller-verification.mjs` for the packaged checks. Model and controller checks do not establish empirical validation.

The parent package's ENGINEERING_STATE.md records the architecture, exact evidence, limitations, historical context and pending work. This package is local only; no public deployment has occurred. Human expert review is optional, not required for release.
