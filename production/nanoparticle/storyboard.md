# Opening choreography

The entire opening is live and yields to deliberate interaction. The same atom instances continue into exploration. Timings are illustrative, not physical kinetics.

| Time | Composition | Explanation |
|---|---|---|
| 0–3 s | Native-resolution panels 1a and 1c, preserving letters and 100 nm bars; source underneath | Start with experimental images |
| 3–6 s | Blue square and violet triangle outlines draw onto the corresponding shape insets | Different shapes expose different faces |
| 6–10 s | Those outlines carry into projected {100} and {111} faces; paper recedes; the ideal model resolves into atoms | Explicit explanatory model, not a photograph reconstruction |
| 10–13 s | Smooth camera approach to the central square-terrace atom; actual neighbors illuminate | Local surroundings on a face |
| 13–16 s | Move along the same crystal to an edge atom | The neighbor count decreases |
| 16–19 s | Move to a vertex | More exposed surroundings |
| 19–20 s | Return along a short camera path to an overall inspection view, with the corner still selected | Hand over control |

Explore is available immediately. Pause freezes the automatic timeline and camera. Drag interrupts without a reset. Explicit shortcuts may request a new camera destination; automatic choreography cannot resume afterward. Reduced motion starts at the completed overview and uses immediate camera changes.

Feedback uses a short interpolation; camera transitions use quintic smootherstep at approximately 850 ms. A new destination begins at the actual current pose and wraps yaw to the shortest route. After the opening, there is no autonomous orbit or atom motion.

Visual references: four editable Blender scenes and renders in this directory. The browser's inspection ring and dynamic cutaways are interaction affordances, not extra scientific structure. Collection artwork is a standalone render from the shared geometry with no controls or module UI.
