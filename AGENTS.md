# Fig.3D project instructions

Read `DESIGN_AND_PRODUCT_HANDOFF.md`, especially “Living preferences”, before making design or interaction changes. It is the persistent record of the user's product mission and preferences; later dated feedback supersedes historical handoff details.

Whenever the user offers a new critique, preference or improvement, update that guide in the same session. Record the concrete problem and durable design principle without presenting unverified work as complete. Preserve existing preferences unless explicitly superseded.

For paper companions, keep selected controls synchronized with the visible content, make source/model comparison immediate and preserve state, give scientific stages visibly distinct explanations, and test transitions in motion. Include actual browser evidence and state any untested limits. Public deployment is a separate action.
